Step 2: The Question This Demo Answers

The agent does not know where the goal is. It does not know a wall is there until it runs into it. The only information it gets after every move is a single number: the reward. Minus one for an ordinary step. Minus ten for landing in the pit. Plus ten for reaching the goal.

Can trial and error alone, with nothing but that one number as feedback, teach the agent the shortest safe path to the goal?

Step 3: Train the Agent

Now give the agent a chance to learn. Each training episode starts the agent back at its starting square and lets it run until it reaches the goal, falls in the pit, or hits the step limit. After every move, it updates its estimate of how good that move was in that square. That estimate is called a Q-value.

Vocabulary: What Each Term Actually Means Here

State: the agent's current grid square. Nothing more. It has no memory of how it got there.
Action: one of four choices available in every state: up, down, left, right.
Reward: the single number the environment returns after each action. It is the only feedback the agent ever receives.
Q-value: the agent's running estimate of how good a specific action is in a specific state, based only on rewards it has actually experienced there.
Policy: the rule the agent uses to pick an action. A greedy policy always picks the action with the highest known Q-value.
Episode: one full run from the starting square to a terminal outcome, either the goal or the pit.
Exploration vs. exploitation: exploration is trying a random action to see what happens. Exploitation is picking the action the agent already believes is best. Epsilon controls how often the agent explores instead of exploiting.
