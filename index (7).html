Reinforcement Learning

Run in the order below, each builds on the vocabulary from the one before it.
Grid World
An agent that starts knowing nothing about a small maze and learns the shortest safe path through nothing but trial, error, and reward. Introduces state, action, reward, policy, Q-value, and episode.
START HERE
The Slot Machines
Four machines, no maze, no movement, just the exploration-versus-exploitation dilemma in its simplest possible form.
Self-Play: Tic-Tac-Toe
An agent that gets better only by playing copies of itself thousands of times, the same basic idea behind AlphaGo and AlphaZero, small enough to fully explore.
Deep Scan: Finding the Cloaked Fleet
A hidden, fixed enemy formation and a scanner that only reports hit or miss. Introduces partial observability, the one idea none of the other demos cover.
