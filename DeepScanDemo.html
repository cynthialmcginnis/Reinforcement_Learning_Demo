Deep Scan: Finding the Cloaked Fleet

Unit 4: Computer/Machine Vision and Reinforcement Learning

COMMAND LOG, SECTOR 7-DELTA. The Sovereign Fleet returned to this system three cycles ago. Their warships run under a full cloaking veil, a field that bends every wavelength your sensors can read. No silhouette. No shadow. No image at all, which means the computer vision systems that serve this ship so well everywhere else are worthless here. There is nothing to look at.

What you do have is a single tactical scanner. Point it at one grid sector, and it tells you exactly one thing: contact, or nothing. That is the entire information budget you have to work with, sector by sector, ping by ping.

Here is the one thing working in your favor. Fleet Command's after-action reports go back six deployments, and every one of them shows the same thing: the Sovereign Fleet's commanders are creatures of pure habit. Same three ships. Same formation. Every single time, as if daring anyone to notice. They are certain that no one can learn a pattern they cannot even see.

Your job is to prove them wrong. Not by seeing the fleet, you can't, but by remembering. Every ping you send teaches the targeting system something the enemy assumes you will forget by the next sweep. Sweep after sweep, if you keep score and adjust, that memory becomes a map, and that map becomes a report Fleet Command can act on.

Step 2: The Question This Demo Answers

Your scanner never sees the fleet directly. All it ever gets back from a ping is contact or nothing, one sector at a time. But because the enemy redeploys in the identical formation every sweep, the same sectors that mattered last time matter again this time.

Can a system learn, purely from the pattern of past contacts and misses, exactly which sectors to check first, until it can report the fleet's position almost immediately?

Step 3: Train the Targeting System

SCANNER LOG — AFTER SWEEP 1. The good news: the ships are still exactly where they were. The Sovereign Fleet did not move, and after action reports confirm they never do. Every sweep against this same sector is a chance for the targeting computer to remember what worked last time and try it again first. Run enough sweeps, and see what it learns.

Once a ping finds a contact, checking the sectors next to it is simply sound tactics, not something that needed to be learned. What genuinely gets learned here, sweep after sweep, is which sectors of the grid are worth checking first, because this enemy never moves.

Step 4: Why This Works So Well

Compare this to the earlier reinforcement learning demos in this unit. In the grid-world maze, every training episode started from the same maze, so the agent could learn exact cell values too. But in a version of this exact game where the fleet redeploys to a new random formation every single sweep, memorizing specific sectors would be worthless, since last sweep's contacts tell you nothing about this sweep's hidden ships. What actually makes this demo work is the enemy's own predictability. An adversary who never changes their pattern is, from a learning system's point of view, the easiest possible adversary to beat. That is a genuine tactical lesson as much as a technical one: predictability is a vulnerability, whether the thing exploiting it is a person or a trained model.

MISSION DEBRIEF. File this for Fleet Command: the enemy was never actually hidden. They were only unseen. A system that cannot look can still learn, provided the world it is acting in holds still long enough to be remembered. The Sovereign Fleet's discipline, the very thing meant to make them look disciplined and unreadable, is exactly what made them predictable enough to learn against. A habit defended once is still a habit. Repeat it against something that remembers, and it stops being a defense at all.

Vocabulary: What Each Term Means Here

State: here, unusually, the state that matters most is simply which sector is about to be pinged, since the same fixed formation lies underneath every sweep.
Action: pinging one specific sector.
Reward: a positive number for a contact, a small negative number for nothing, credited immediately after each individual ping rather than only at the end of a sweep.
Q-value: the learned value of pinging a specific sector, built up across many sweeps against the same fixed formation. Watch the Intelligence Map in Step 3: over enough training, the brightest sectors on that map should start to trace the actual outline of the hidden fleet.
Epsilon (exploration rate): the probability, on any given ping, that the targeting computer ignores its current best guess and checks a random sector instead. This is the same exploration-versus-exploitation tradeoff from the slot machine demo earlier in this unit, just applied to a grid instead of four levers. Too low, and an early lucky or unlucky ping can lock in a bad habit permanently. Too high, and the system never settles down enough to actually use what it has learned.
