Step 2: The Question This Demo Answers

Nobody is going to hand this agent a database of expert tic-tac-toe games. Instead, it is going to play against a copy of itself, thousands of times in a row, learning only from whether each finished game was a win, a loss, or a draw.

Can an agent become genuinely hard to beat using nothing but its own games against itself, the same basic idea behind DeepMind's AlphaGo and AlphaZero, just on a board small enough to fully explore?

Vocabulary: What Each Term Means Here

Self-play: training an agent by having it compete against a copy of itself rather than against human data or a fixed opponent. Both sides improve together, which keeps generating harder and harder practice as training goes on.
Terminal reward: a reward that only arrives at the very end of an episode, here plus one for a win, minus one for a loss, zero for a draw. Every move earlier in the game had to have its value inferred backward from that single end-of-game signal.
Credit assignment: the problem of figuring out which of the many moves in a finished game actually deserved credit for the win or blame for the loss. This is a much harder version of the same problem the grid-world agent solved one step at a time.
