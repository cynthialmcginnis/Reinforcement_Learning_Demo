Step 2: The Question This Demo Answers

You cannot see the true odds behind any machine. The only way to learn anything about a machine is to pull its lever and observe one outcome. Every pull you spend on a machine you already trust is a pull you did not spend checking whether a different machine is secretly better.

Can an algorithm, using nothing but the same blind pulls you just made, reliably find the best machine without wasting too many pulls finding out?

Step 3: Watch an Algorithm Learn

This is the same four machines, with the same hidden payout odds, but now an automated agent is pulling the levers. It uses a simple rule called epsilon-greedy: most of the time it pulls whichever machine currently looks best (exploitation), but some percentage of the time, controlled by the slider below, it pulls a random machine instead just to keep checking (exploration).

Step 4: Try the Extremes

Set epsilon to 0 and reset, then run 100 pulls. The algorithm will exploit whatever it liked after its very first few pulls and never check again, even if that early impression was wrong. Then set epsilon to 1 and reset, then run 100 pulls again. The algorithm will pull randomly forever and never settle on anything, even after it has clearly learned which machine is best. Neither extreme works. That is the entire dilemma in this unit's vocabulary: exploration versus exploitation.

Vocabulary: What Each Term Means Here

Action: pulling one specific machine's lever. There are only four possible actions in this entire problem.
Reward: the payout from a single pull, win or lose. There is no state here, unlike the grid-world demo. Every pull starts from the same situation, which is what makes this the simplest possible reinforcement learning problem.
Estimated value: the running average payout the algorithm has observed so far for a given machine. This estimate can be wrong, especially early on, with only a few pulls behind it.
Epsilon-greedy policy: a policy that exploits its current best estimate most of the time, and explores a random action the rest of the time, at a rate controlled by epsilon.
